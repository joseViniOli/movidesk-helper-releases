# Movidesk Helper - Releases

Este repositório contém **somente os pacotes de distribuição** do Movidesk Helper. Ele não tem código-fonte: os arquivos das releases são publicados automaticamente a partir do repositório de desenvolvimento.

## Arquivos de cada release

| Arquivo | Para que serve |
|---|---|
| `movidesk-helper.zip` | Pacote para instalação "sem compactação" (`chrome://extensions`) |
| `version.json` | Versão e hash do pacote, lido pela auto-atualização da extensão |
| `movidesk-helper.crx` | Pacote assinado para instalação por política do Chrome |
| `updates.xml` | Manifesto de atualização usado pelo Chrome com o `.crx` |

Baixe sempre a versão mais recente na aba **Releases**.
